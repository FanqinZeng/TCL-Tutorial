# 无障碍与布局

语义化 header/nav/main/footer、跳到正文、可见焦点、带名称的代码区、运行状态 live region、原生 details 提示与答案。编辑器的 Tab 默认离开输入区域；Ctrl/⌘ + Enter 运行。

桌面为阅读 + 工作台双栏。手机先显示问题、目标与教材示意，再显示代码和结果，随后继续正文与练习。代码可单独横向滚动；表格和列表在窄屏折行，页面不应整体横向溢出。

通过“动态开启/关闭”选择轻量反馈；prefers-reduced-motion 禁止动画。状态同时有文字、符号与颜色。错误与超时有具体提示，不显示成功结果。

每张 SVG 包含 title 和 desc，页面提供 alt 和教材示意标记。视频提供中文字幕、封面和逐字稿，不依赖声音。英文入口仅切换完整首页/指南/课程概要，明确主课程正文是中文。
