# Authoring contract

Original course sources are `lessons/01.json` … `18.json`, and `projects/A.json` … `F.json`. Generated Markdown, Tcl files and site JSON are produced by `scripts/build.py`; edit sources rather than generated files.

Lesson object: `id` (number), `unit` (1..6), `title`, `summary`, `minutes`, `prerequisites` (string array), `objectives` (3..5 strings), `problem`, `steps` (array of {title,body}), `examples` (at least 3 {title,code,expected,files?,argv?}), `exercises` (at least 3 {title,prompt,starter,solution,expected,hints:[string,string],checks:[{label,script}],files?,argv?}), `mistakes` (at least 2 {problem,fix}), `exploration`, `quiz` (at least 2 {question,options:[strings],answer:zero-based-index,explanation}), `cheatsheet` (array of strings), `next`, `view` (one of output,variables,substitution,branches,iterations,list,text,record,regex,procedure,files,errors,scope,modules,objects,paths,pipeline), `diagram` (relative SVG path `assets/diagrams/01.svg`).

Project object: `id` (A..F), `title`, `summary`, `requirements` (strings), `input` (description), `starter`, `solution`, `expected` (stdout), `hints` (3 strings), `cases` (at least 3 {title,code,expected,checks?:[{label,script}],files?,argv?}), `checks` ([{label,script}]), `files` (path→text optional), `argv` (string array optional), `extensions` (strings), `view`, `diagram` (`assets/diagrams/project-A.svg`). Cases can source the same solution then call functions with varied inputs; avoid hardcoded-answer tests. Case `code` is executed AFTER solution (solution's stdout is captured separately); case expected is only case-code stdout. Every code execution is fresh, in `/work` in browser / temporary directory locally. Files are relative, no `..`, no absolute paths. `expected` omits final newline. Checks run after code, must return Tcl boolean `1`, and should not print.

SVG diagrams: authors create them directly, topic-specific, accessible `<title>` and `<desc>`, viewBox and width/height, neutral cream/teal/orange palette, no remote assets. Files fixtures are original teaching data, never private information. Required Tcl: 8.6+. Root integrates website/runtime/tests and all generated outputs; authors only own their specified JSON and diagram files. Root has bundled Python `tkinter.Tcl()` exposing native Tcl 9.0.4 for validation; browser runtime Tcl version will be measured.
